# Learning Tasks - Start Here!

**Learning by building.** Work through these tasks from easy to hard.

## Getting Started

1. Read the task file
2. Try to build it yourself
3. Check hints only if stuck
4. Run the test/code to verify
5. Move to next task

- Google is your friend
- Break things and fix them
